## Question

Form elements driven by state vs native DOM state.

## Expected Answer

Form elements driven by state vs native DOM state.

## Deep Explanation

A Controlled Component is an input form element whose value is fully driven and controlled by React component state. Any change triggers a handler that updates the state.
