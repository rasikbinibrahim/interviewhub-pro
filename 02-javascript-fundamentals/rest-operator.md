## Question

Spread expands iterables; rest collects arguments into an array.

## Expected Answer

Spread expands iterables; rest collects arguments into an array.

## Deep Explanation

The rest parameter syntax (...) allows a function to accept an indefinite number of arguments as an array, or destructures remaining elements of arrays/objects. It must always be the last parameter in the destructuring/function parameter list.
