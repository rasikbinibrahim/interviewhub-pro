## Deep Explanation

An Execution Context is an abstract environment in which JavaScript code is evaluated and executed. Every execution context has two phases: a Creation Phase (where the scope chain, variable object, and 'this' are set up) and an Execution Phase (where code is executed line-by-line). There is a Global Execution Context and a Function Execution Context for each function call.
