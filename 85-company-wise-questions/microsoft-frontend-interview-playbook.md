# T8515 · Microsoft Frontend Technical Interview Playbook: TypeScript Architecture, Accessibility & Office Web

**Difficulty:** Hard  
**Companies Asked:** Microsoft  
**Category:** Company-wise Questions  
**Concepts:** microsoft, frontend-interview, playbook, typescript, accessibility, office-web  

## Comprehensive Guide

This playbook details the specific structure, grading rubrics, and technical expectations evaluated during **Microsoft Senior Software Engineer (Web / UI)** technical interviews.

### Key Evaluation Areas
1. **Advanced TypeScript Competency**: Generics, conditional types, mapped types, declaration files, and strict type safety patterns.
2. **Accessibility & WAI-ARIA Standards**: Complete keyboard navigation (Tab / Arrow keys), ARIA roles, and screen reader announcements.
3. **Office Web / VS Code Architecture**: File tree views, Monaco Editor integration, Virtual DOM diffing, and extension host RPC protocols.
