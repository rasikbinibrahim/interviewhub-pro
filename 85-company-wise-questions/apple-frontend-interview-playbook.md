## Comprehensive Guide

This playbook details the specific structure, grading rubrics, and technical expectations evaluated during **Apple Senior Web/UI Software Engineer** technical interviews.

### Key Evaluation Areas
1. **60/120 FPS UI Animation & Canvas**: Smooth cubic-bezier transitions, hardware-accelerated transforms, WebGL/WebGPU graphics rendering.
2. **Pixel-Perfect UI Execution**: Meticulous attention to typography, spacing, responsive layout dynamics, and micro-interactions.
3. **Clean Code Craftsmanship**: Modular architecture, zero external dependency implementations, and robust edge-case handling.
