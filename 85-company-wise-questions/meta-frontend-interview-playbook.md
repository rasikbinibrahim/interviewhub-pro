# T8513 · Meta Frontend Technical Interview Playbook: Machine Coding, React Fiber & Large-Scale Design

**Difficulty:** Hard  
**Companies Asked:** Meta  
**Category:** Company-wise Questions  
**Concepts:** meta, frontend-interview, playbook, machine-coding, react-fiber  

## Comprehensive Guide

This playbook details the specific structure, grading rubrics, and technical expectations evaluated during **Meta Senior Front End Engineer (E5/E6)** technical interviews.

### Key Evaluation Areas
1. **Speed Machine Coding (45 Minutes)**: Building fully functional interactive UI components (Autocomplete, Infinite Scroll, Star Rating, Nested Checkboxes) from scratch without external libraries.
2. **React Internals**: Concurrent React, Fiber reconciliation, synthetic events, and custom hook primitives.
3. **Large Scale System Design**: Designing Facebook News Feed, Messenger Web, or Instagram Web Client.
