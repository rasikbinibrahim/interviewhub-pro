# T8507 · Netflix Frontend Technical Interview Playbook: Streaming Systems, TV UI & Performance

**Difficulty:** Hard  
**Companies Asked:** Netflix  
**Category:** Company-wise Questions  
**Concepts:** netflix, frontend-interview, playbook, streaming, performance  

## Comprehensive Guide

This playbook details the specific structure, grading rubrics, and technical expectations evaluated during **Netflix Senior UI Engineer** technical interviews.

### Key Evaluation Areas
1. **Media & Streaming Engine Architecture**: Deep knowledge of HLS/DASH streaming, Media Source Extensions (MSE), and adaptive bitrate (ABR) buffer management.
2. **TV & TV-OS UI Navigation**: D-Pad arrow key spatial navigation algorithms (`spatial-navigation-js`) for smart TVs and TV devices.
3. **Core Web Vitals & Startup Time**: Reducing initial JavaScript bundle parse times for low-powered TV hardware.
