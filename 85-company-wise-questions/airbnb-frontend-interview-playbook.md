This playbook details the specific structure, grading rubrics, and technical expectations evaluated during **Airbnb Senior Frontend Engineer** technical interviews.

1. **Design System Architecture**: Tokenized design systems, component composition, and CSS architecture (Lunar / Visx).

3. **Frontend System Design**: Designing an interactive listing search page with map sync, pagination, and dynamic filter parameters.
