# T8512 · Google Frontend Technical Interview Playbook: JavaScript Internals, Web Vitals & System Design

**Difficulty:** Hard  
**Companies Asked:** Google  
**Category:** Company-wise Questions  
**Concepts:** google, frontend-interview, playbook, web-vitals, js-internals  

## Comprehensive Guide

This playbook details the specific structure, grading rubrics, and technical expectations evaluated during **Google Senior Software Engineer (Frontend/Web)** technical interviews.

### Key Evaluation Areas
1. **Core JavaScript & DOM Internals**: Event loop microtask order, V8 hidden classes, garbage collection, and custom DOM node polyfills.
2. **Web Vitals & Performance**: Optimizing INP, LCP, CLS, critical rendering path, and main thread offloading via Web Workers.
3. **Frontend System Design**: Designing Google Docs, Google Maps WebGL, or YouTube Player Architecture.
