# T8511 · LinkedIn Frontend Technical Interview Playbook: Feed Architecture, Accessibility & Performance

**Difficulty:** Hard  
**Companies Asked:** LinkedIn  
**Category:** Company-wise Questions  
**Concepts:** linkedin, frontend-interview, playbook, feed-architecture, a11y  

## Comprehensive Guide

This playbook details the specific structure, grading rubrics, and technical expectations evaluated during **LinkedIn Senior UI Engineer** technical interviews.

### Key Evaluation Areas
1. **Virtual Feed Performance**: Windowing long posts, lazy loading images/videos, and monitoring INP / LCP Core Web Vitals metrics.
2. **Inclusive Design (WAI-ARIA)**: Screen reader navigation for complex feeds, rich text editors, and comment threads.
3. **Frontend System Design**: Designing LinkedIn Messaging or Notification Center architecture.
