## Format

This section holds **coding questions**, not concept pages — every
question here follows [QUESTION_TEMPLATE.md](../QUESTION_TEMPLATE.md)
(23 required fields: problem statement, constraints, examples, edge
cases, hints, algorithm, dry run, JS + TS solutions, complexity, common
mistakes, follow-ups, similar questions), generated via
[docs/prompts/coding-question-generator.md](../docs/prompts/coding-question-generator.md).
This is different from most other sections in this repo, which use the
broader concept-page [TEMPLATE.md](../TEMPLATE.md) — DSA is coding
practice, not theory explanation, so it gets the coding template.

Study order follows [ROADMAP.md](../ROADMAP.md) Phase 2 — patterns build
on each other; see that file before jumping to an advanced pattern first.
